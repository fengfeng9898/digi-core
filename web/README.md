# 网页预览（不需要硬件）

直接用浏览器打开 `preview.html` 即可（双击就行，data.js 是普通脚本，file:// 也能加载）。

## 能做什么

- **画面**：64×64 像素级还原固件布局（状态栏心形、心情条、动画、便便、底部文字），用的是同一套 5×7 字库和同一份动画帧
- **操作**：喂食 / 清洁 / 训练 / 战斗 / 安抚 / 睡觉 / 唤醒 / 进化检查 / 卡片
- **战斗是回合制切镜**（不是左右分屏，每镜只有一个角色）：
  1. 敌方单独登场 `GREYMON!`
  2. 我方单独攻击 `GO!`
  3. 切到敌方单独受伤 `HIT!`
  4. 赢了 → 敌方定格倒下 `KO!` → 我方胜利动作 `YOU WIN!`
  5. 输了 → 敌方单独攻击 `ENEMY!` → 我方单独受伤 `OUCH!` → `DEFEAT`
- **时间加速**：1× / 60× / 600× / 3600×，3600× 下约 6 分钟走完 15~30 天
- **自动照料**：自动喂食/清洁/战斗/用勇气卡，用来验证完整进化链
- **事件流**：便便、野生遭遇、生病、捡东西、呼唤，以及被无视

## 随机退化

- 触发条件（每小时最多判一次）：**饿到 0**（5%/h）、**重伤 HP<15**（1%/h）、**生病**（0.5%/h）
- 一旦触发，会掉到**当前阶段以下的任意阶段**（最低幼年期，不会回到蛋）
- 退化后：胜场清零、攻防 ×0.7、心情 -15，需要重新攒胜场才能再进化
- 平衡：正常照料 500 局 99.6% 仍能在 16~30 天到究极体；放任不管 300 局里 247 局会退化（中位 10 小时）

## 敌方角色：小丑王（JOKER）

- 素材是三视图（正面 / 侧面 / 背面），没有中间帧，动作用**姿态切换 + 位移 + 挤压 + 特效**合成
- 四组动作：待机（正面呼吸）、攻击（蓄力→侧身突进+斩击）、受伤（抖动+闪白）、胜利（弹跳+星星→背面叉手）
- 生成：`python tools/make_joker.py` → `web/joker_data.js` + `docs/joker_*.gif` + 逐帧条
- 敌方池：滚球兽 / 亚古兽 / 暴龙兽 / 小丑王；小丑王不加暗色滤镜（本身配色就够跳）

## 战斗卡（临时进化）

- 点「⚔️ 战斗卡」拿一张，状态栏显示「就绪」
- 下一场战斗以**进化一级的形态**参战（攻 +8 / 防 +6），战斗结束**回到原阶段**
- 需要素材支持：目前只有滚球兽/亚古兽/暴龙兽有动画，进化到机械暴龙兽/战斗暴龙兽时视觉会退回当前形态（逻辑仍然生效）
- 演出：开战多一个 `CARD!` 镜头，结尾显示 `REVERT..`

## 背景（白天/黑夜）+ 时钟

- **跟真实时间走**：背景按你电脑/设备的实际北京时间切换（6:00–18:00 白天，其余黑夜），不受游戏加速影响
- **左下角显示 HH:MM**（青色像素字，带黑色描边），右下角显示当前阶段（`CHILD` / `ADULT` / `ULT`）
- 场景图由 tools/import_backgrounds.py 压成 64×56、24 色索引图（web/bg_data.js）
- 面板上的「自动 / 白天 / 黑夜」可以手动锁定场景（调试用）
- **只有云在动**：3 朵云缓慢横移并循环出屏，草地、山、城市、月亮全部静止
  （	ools/test_bg.js 会验证：云区域有位移、静态区域 0 像素变化）

## 数据从哪来

`data.js` 由 `tools/build_web_preview.py` 从固件头文件导出：

```bash
python tools/build_web_preview.py   # 重新导出（改了动画/精灵后跑一次）
```

- 精灵帧：`src/assets/sprites.h` + `src/assets/anim_data.h`
- 字库：`.pio/libdeps/.../glcdfont.c`（和真机同一套）
- 规则：`web/game.js` 逐条对齐 `src/game/pet.cpp`

## 自测

```bash
node tools/test_game.js     # 500 次养成，对齐 Python 模拟器（中位 ~22 天）
node tools/test_render.js   # 无头渲染冒烟：画面非空、动画推进、战斗序列、兜底
```

## 和真机的差别

| 项目 | 预览 | 真机 |
|---|---|---|
| 色彩 | 24 位屏幕渲染 | 6bit/通道 RGB565，LED 观感更硬 |
| 帧率 | 浏览器 60fps | 15fps 渲染 + DMA 刷新 |
| 声音 | 无 | 蜂鸣器（尚未实现） |
| 时间 | 可加速 | 真实时间 + NTP |
